=== SLIDE 5 ===
研究内容
研究
意义
在
订单取消率不断提高的今天，如何平衡订单取消带来的成本压力与提高服务水平的竞争压力是面对电商平台的一个重要问题。目前，电商平台普遍采用的履约方式是订单到达时直接将订单下单。通过策略的选择在保持服务水平的前提下降低成本是电商平台迫切的需求
。
课题目标
课题对某电商平台的订单履约过程进行问题描述和建模，并进行优化、求解和验证，开发订单履约优化小软件，帮助企业解决因订单取消而造成的成本上升问题。

随机优化问题模型
Powell
（
2019
）在论文中总结了随机优化的常见模型及描述方式，适应的问题以及常见的求解方法。本问题中，我们将主要使用马尔可夫决策过程的方式建立模型，并利用成本函数近似的方式优化策略。
Bellman
（
1957
）提出了马尔可夫决策过程，
Howard
（
1960
）继续了这一工作，
 
Puterman
（
2005
）关于马尔可夫决策过程的书籍在之后被广泛引用。
成本函数近似
Powell (2019) 
的论文中总结了成本函数近似（
Cost function approximation, CFA
）、值函数近似（
Value function approximations, VFA
）、策略函数近似（
Policy function approximations, PLA
）
 
和直接前瞻近似（
Direct lookahead, DLA
）的方法。
在面对非确定性的问题时，
Perkins 
和 
Powell 
（
2017
）提出了成本函数近似的方法。分别介绍了成本函数近似的具体内容，适用模型以及求解方法。提出了梯度下降等求解方法
。
